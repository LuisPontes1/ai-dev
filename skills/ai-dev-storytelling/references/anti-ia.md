# Cheiro de IA — o que remover

Texto de modelo tende à média. Estes são os sinais que o leitor já reconhece. Passe o texto por esta lista
antes de entregar.

## Aberturas
- "No mundo atual / Nos dias de hoje / Em um cenário cada vez mais…" → corte; comece pela cena.
- "Você já se perguntou…?" → troque pela resposta, afirmada.
- "Vamos mergulhar / Vamos explorar / Neste post vou…" → corte; só faça.
- "Fiquei muito feliz / honrado / animado em compartilhar…" → corte.

## Palavras e muletas
- "fascinante", "revolucionário", "game changer", "divisor de águas", "jornada", "potencializar",
  "alavancar", "robusto", "sinergia", "no fim do dia", "isso muda tudo".
- Intensificadores vazios: "extremamente", "incrivelmente", "verdadeiramente".
- "Vale ressaltar / Vale destacar / É importante notar" → só diga a coisa.

## Construções
- "Não é X, é Y" usado mais de uma vez. Uma vez é ênfase; três é tique.
- Tríades em todo lugar ("rápido, simples e eficaz"). Use três só quando são mesmo três.
- Travessões encadeando apostos em toda frase.
- Dois-pontos com revelação ("O segredo? Consistência.") e "Spoiler:".
- Pergunta retórica seguida da própria resposta ("O resultado? Incrível.").
- Uma frase por linha em todo o texto, para fingir ritmo. Use quebra curta só no momento de impacto.

## Formatação
- Emoji como marcador de seção ou de bullet (🚀 ✅ 💡 👉).
- Negrito em metade das frases. Negrito marca uma coisa, no máximo duas.
- Lista de "lições aprendidas" no fim repetindo o texto.
- Bloco de hashtags.

## Conteúdo
- Afirmação sem prova ("aumentou muito a produtividade") → número, cena ou corte.
- Generalização sobre "as empresas" / "os profissionais" → fale do seu caso.
- Equilíbrio falso ("por um lado… por outro…") quando o autor tem posição → assuma a posição.
- Fechamento perguntando a opinião do leitor de forma genérica.

## Teste final
Tampe o nome do autor. Alguém que conhece o autor reconheceria a voz? Se parece que qualquer pessoa poderia
ter escrito, falta especificidade: empresa, número, cena, opinião.
